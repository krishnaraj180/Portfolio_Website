# Krishnaraj R. — Animated Developer Portfolio

Premium recruiter-friendly portfolio based on the supplied portfolio specification.

## Stack
- Next.js
- JavaScript / JSX
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Vercel-ready

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Before deploying
1. Replace `your-email@example.com` with the real email.
2. Replace the LinkedIn `#` links.
3. Replace project `live` and `github` placeholders.
4. Add screenshots to `public/images/` and wire them into `Projects.jsx`.
5. Put the final resume at `public/resume.pdf`.
6. Run `npm run build`.
7. Push to GitHub and deploy to Vercel.

## Content basis
The section structure, visual direction, animation requirements, technology stack and recommended project content follow the uploaded portfolio specification.
